# Правила работы с проектом

## Область проекта

- Разрабатывайте только HTTP API калькулятора. Не добавляйте веб-интерфейс, мобильное приложение или CLI без отдельного запроса.
- Источник истины для публичного API — `openapi.yaml`. При изменении метода, схемы или кодов ошибок сначала обновляйте контракт, затем реализацию, тесты и `README.md`.
- Не добавляйте новые операции или параметры без отражения в контракте.

## Поведение API

- Реализуйте `POST /api/v1/calculate` с операциями `add`, `subtract`, `multiply`, `divide` над полями `a` и `b`.
- Сохраняйте порядок операндов: `subtract` означает `a - b`, `divide` — `a / b`.
- Возвращайте только конечные числа JSON. Деление на ноль и неконечный результат обрабатывайте ошибками из контракта.
- Для неверного JSON, отсутствующих или лишних полей, неверных типов и неизвестной операции возвращайте `400 INVALID_REQUEST`.
- Для арифметических ошибок возвращайте `422` с кодом `DIVISION_BY_ZERO` или `NON_FINITE_RESULT`.
- Не возвращайте стек вызовов или внутренние детали сервера в ответе API.

## Проверка изменений

- Проверяйте четыре операции, порядок операндов, ноль в делителе, некорректный запрос и неконечный результат.
- Поддерживайте примеры и описание в `README.md` в соответствии с `openapi.yaml`.
