# Calculator API

Проект калькулятора с HTTP API. Интерфейс пользователя не входит в текущую область проекта.

## Контракт

Публичный контракт описан в [openapi.yaml](openapi.yaml) (OpenAPI 3.1). Реализации сервера в репозитории пока нет; адрес `http://localhost:8000` в контракте — предполагаемый адрес локального сервера.

## Вычисление

`POST /api/v1/calculate` принимает JSON с тремя обязательными полями:

| Поле | Тип | Значение |
| --- | --- | --- |
| `operation` | string | `add`, `subtract`, `multiply`, `divide` |
| `a` | number | Первый операнд |
| `b` | number | Второй операнд |

Для `subtract` вычисляется `a - b`, для `divide` — `a / b`. Дополнительные поля запрещены.

Пример запроса:

```http
POST /api/v1/calculate HTTP/1.1
Content-Type: application/json

{"operation":"divide","a":12,"b":3}
```

Успешный ответ (`200`):

```json
{"result":4}
```

Числа передаются как числа JSON. Возможна обычная погрешность вычислений с плавающей точкой; точная десятичная арифметика контрактом не предусмотрена.

## Ошибки

Все ошибки имеют формат `{"error":{"code":"...","message":"..."}}`. Клиенту следует проверять `code`, а не текст `message`.

| HTTP | `code` | Условие |
| --- | --- | --- |
| 400 | `INVALID_REQUEST` | Неверный JSON, отсутствующее/лишнее поле, неверный тип или неизвестная операция |
| 422 | `DIVISION_BY_ZERO` | Делитель равен нулю |
| 422 | `NON_FINITE_RESULT` | Результат невозможно представить конечным числом JSON |

Пример ошибки:

```json
{"error":{"code":"DIVISION_BY_ZERO","message":"Деление на ноль невозможно."}}
```
